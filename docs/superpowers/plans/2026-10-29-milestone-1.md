# wattsim Milestone 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Bun/TypeScript library and CLI that simulates OCPP 1.6J and 2.0.1 charge points against any CSMS, driven by a custom scenario DSL, with an EV physics model, a virtual clock, strict schema validation, deterministic fault injection and a Prometheus endpoint.

**Architecture:** Four workspace packages. `@wattsim/protocol` owns OCPP-J framing and schema validation (Zod generated from vendored OCA schemas). `@wattsim/core` owns the clock, EV and meter models, the WebSocket connection with chaos middleware, and the `Station` state machine with per-version adapters. `@wattsim/scenario` owns the DSL (lexer, parser, AST, formatter, interpreter). `wattsim` is the citty CLI. Everything is driven through one `Clock` so tests and fast-forward runs are deterministic.

**Tech Stack:** Bun 1.4, TypeScript 5.9, Zod 4, `json-schema-to-zod` (generator, dev-only), Ajv (test oracle only), `prom-client`, `citty`, Biome, lefthook, `bun test`.

**Spec:** `/Users/joni/koodaus/ocpp-simulator/DESIGN.md`

## Global Constraints

- Runtime is Bun. Use `Bun.serve`, Bun's global `WebSocket`, `Bun.file`. No `ws`, no `node:http` servers.
- Biome style: 2-space indent, single quotes, line width 120. `bun run lint` must pass. `tsc --noEmit` must pass with `strict`, `noUncheckedIndexedAccess`, `verbatimModuleSyntax` (use `import type`).
- Every package exports from `src/index.ts` only. Cross-package imports go through the package name (`@wattsim/protocol`), never relative paths.
- Generated code lives in `packages/protocol/generated/` which is gitignored. Vendored schemas in `packages/protocol/schemas/` are never modified.
- No wall-clock calls (`Date.now`, `setTimeout`, `performance.now`) anywhere in `core` or `scenario` except inside `WallClock`. Everything takes a `Clock`.
- Tests are `bun test`, files named `*.test.ts` under each package's `test/` directory. No test touches the network except through the in-repo `FakeCsms`.
- Subprotocol strings are exactly `ocpp1.6` and `ocpp2.0.1`.
- Commit messages: imperative, sentence case, plain English. Subagents do not commit; the orchestrator commits per wave.

## Review Focus

1. A CSMS that never answers a CALL: the station must time out (default 30 s virtual), surface an error event, and keep heartbeating. Test in Task 6.
2. Network drop mid-transaction: MeterValues and StopTransaction generated offline must queue and flush in order on reconnect, with no duplicates unless chaos asks for them. Test in Task 6.
3. CSMS returns a CALLERROR or schema-invalid CALLRESULT: strict mode records a violation and rejects the pending request; the station does not crash. Test in Task 6.
4. DSL file with a syntax error: `wattsim check` prints `file:line:col: message` and exits 1; nothing connects. Test in Task 7 and Task 9.
5. Virtual clock at 100× speed with 1000 stations: heartbeats and meter intervals stay per-station correct (no shared timers), memory per idle station under 50 KB. Test in Task 6 (correctness) and Task 10 (measurement).

export type Timer = { cancel(): void };
export interface Clock {
  now(): number;                                    // epoch ms, this clock's view
  date(): Date;
  setTimeout(fn: () => void, ms: number): Timer;
  setInterval(fn: () => void, ms: number): Timer;
  sleep(ms: number): Promise<void>;
}
export class WallClock implements Clock {}
export class VirtualClock implements Clock {
  constructor(startMs?: number);
  advance(ms: number): Promise<void>;               // fires due timers in order, awaits microtasks between
  advanceTo(epochMs: number): Promise<void>;
  runUntilIdle(maxMs: number): Promise<void>;       // advance until no timers or maxMs reached
  pendingTimers(): number;
}
export class SkewedClock implements Clock {         // per-station offset + drift over a base clock
  constructor(base: Clock, opts: { offsetMs?: number; driftPpm?: number });
}
export function isoTimestamp(c: Clock): string;     // ISO 8601 with ms, UTC 'Z'

// ev.ts
export type EvConfig = {
  batteryKwh: number;            // default 60
  initialSoc: number;            // 0..1, default 0.2
  targetSoc: number;             // 0..1, default 0.8
  maxCurrentA: number;           // per phase, default 32
  phases: 1 | 3;                 // default 3
  curve?: (soc: number) => number;  // fraction 0..1 of max power allowed at soc; default: 1.0 until 0.8, linear to 0.1 at 1.0

};

export class EvModel {

}

  reset(): void;                                    // for chaos: meter reset
  setEnergyWh(wh: number): void;                    // for chaos: backwards reading
}

```ts
// chaos.ts
export type ChaosMatch = { direction?: 'in' | 'out'; action?: string; nth?: number; every?: number; probability?: number };
export type ChaosEffect =
  | { kind: 'drop' } | { kind: 'delay'; ms: number } | { kind: 'duplicate'; count?: number }
  | { kind: 'corrupt' }                              // flips the raw string into invalid JSON
  | { kind: 'wrongId' } | { kind: 'callError'; code?: string }
  | { kind: 'noResponse' }                           // swallow the matching inbound CALL so no CALLRESULT is sent
  | { kind: 'mutate'; fn: (payload: unknown) => unknown };
export type ChaosRule = { id?: string; match: ChaosMatch; effect: ChaosEffect; once?: boolean };
export type ChaosDecision = { effect: ChaosEffect | null; rule?: ChaosRule };
export class ChaosEngine {
  constructor(rng?: () => number);                   // seedable; default deterministic LCG seeded 1
  add(rule: ChaosRule): string; remove(id: string): void; clear(): void;
  decide(direction: 'in' | 'out', frame: Frame): ChaosDecision;  // counts per (direction, action) for nth/every
}

// connection.ts
export type ConnectionState = 'Disconnected' | 'Connecting' | 'Connected';
export type ConnectionOptions = {
  url: string; identity: string; version: OcppVersion; clock: Clock;
  basicAuth?: { user: string; password: string };
  requestTimeoutMs?: number;                         // default 30000
  reconnect?: { initialMs: number; maxMs: number; factor: number } | false; // default {1000, 60000, 2}
  chaos?: ChaosEngine;
  strict?: boolean;                                  // default true: validate out/in payloads via protocol.validatePayload
};
export type ConnectionEvents = {
  state: [ConnectionState]; frame: ['in' | 'out', Frame, string /*raw*/];
  violation: [Violation]; error: [Error]; chaos: [ChaosRule, Frame];
  call: [CallFrame, (result: unknown) => void, (code: string, desc: string) => void]; // inbound CALL dispatch
};
export class Connection extends TypedEmitter<ConnectionEvents> {
  constructor(opts: ConnectionOptions);
  readonly state: ConnectionState;
  connect(): Promise<void>; disconnect(code?: number): Promise<void>;
  request(action: string, payload: unknown): Promise<unknown>;   // queues while offline; rejects on CALLERROR/timeout/violation(strict)
  queuedCount(): number;
}
```

Behavior: outbound CALLs while disconnected go to an in-order queue and flush on reconnect; one CALL in flight at a time per OCPP-J (next sent after result). Chaos applies in `send` (direction `out`) and in `onmessage` (direction `in`) before any other processing. `wrongId` on `out` rewrites the frame id so the CSMS result won't match; on `in` rewrites the incoming id so the station ignores it. Timeout uses `clock.setTimeout`. Reconnect backoff uses the clock too.

`test/fake-csms.ts`: `class FakeCsms { static start(opts?: { port?: 0; version?: OcppVersion; autoReply?: boolean }): Promise<FakeCsms>; url: string; received: Frame[]; send(identity, frame): void; call(identity, action, payload): Promise<unknown>; respondWith(action, fn: (payload)=>unknown): void; dropClient(identity): void; stop(): Promise<void> }` using `Bun.serve` websockets, negotiating the subprotocol from `Sec-WebSocket-Protocol`. Default replies: BootNotification → Accepted with interval 300, Heartbeat → currentTime, Authorize → Accepted, StatusNotification → {}, StartTransaction → transactionId incrementing, StopTransaction → {}, MeterValues → {}, TransactionEvent → {}. Any other → CALLERROR NotImplemented.

             | 'at' '+' duration block                   // schedule concurrently, relative to enclosing block start

duration    := NUMBER ('ms'|'s'|'m'|'min'|'h')
jsonValue   := JSON object/array/literal, with STRING interpolation "{i}" and IDENT refs allowed as values
expr        := STRING | NUMBER | IDENT | duration
block       := '{' stmt* '}'

```ts
export type RunOptions = {
  clock: Clock;                                     // VirtualClock for tests/fast runs, WallClock for real time

};
export type RunEvent =
  | { type: 'log'; station?: string; message: string; at: number }
  | { type: 'frame'; station: string; direction: 'in' | 'out'; frame: Frame; at: number }
  | { type: 'assert'; station: string; ok: boolean; expect: string; message?: string; at: number }
  | { type: 'violation'; station: string; violation: Violation; at: number }
  | { type: 'station'; station: string; status: 'started' | 'finished' | 'failed'; error?: string; at: number };
export type StationResult = { name: string; ok: boolean; asserts: { ok: boolean; expect: string; message?: string }[]; error?: string; durationMs: number };

export function run(scenario: Scenario, opts: RunOptions): Promise<RunResult>;
export function toJUnit(r: RunResult, suiteName?: string): string;   // one <testcase> per station, <failure> per failed assert or error
```

Semantics: each station block instance runs as an independent async task on the shared clock. `at +d { }` spawns a concurrent branch delayed `d` from the enclosing block's start time. `expect A {partial} within d` waits for the next frame (either direction) whose action is `A` and whose payload deep-partial-matches; on timeout the assert fails and the station continues (fail-soft) unless `fail` is used. `choose` picks a branch per station instance using a seeded rng (seed = hash of station name) so fleets are reproducible. `wait until B` / `barrier B` implement a counting barrier across all instances that declare it. `chaos` adds a rule to that station's ChaosEngine. `clock speed N` is only meaningful with WallClock (`speed` override) and is ignored with VirtualClock. `clock skew`/`drift` wrap the station's clock in `SkewedClock`. `net drop d` disconnects and reconnects after `d`. `let` and loop variables interpolate into strings. `proc`/`call` inline the body.
